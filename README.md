## 🧑‍💻 What is kokoro-web?

kokoro-web is a simple web app that turns text into natural-sounding speech. It uses advanced AI technology to read your text out loud right in your browser. You do not need any special skills or software to use it.

The app works on Windows computers using modern web browsers. It runs fast and does not require installing extra software or plugins. You can listen to your text easily and clearly.

---

## 📋 Features

- Convert your text into speech instantly.
- Supports many languages and voices.
- Runs fully on your computer using WebGPU for speed.
- Easy-to-use interface designed for all users.
- Works offline once loaded in the browser.
- Uses open technologies like ONNX and React.
